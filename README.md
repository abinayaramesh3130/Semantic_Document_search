# Semantic Document Search

## Project Description
This project implements Semantic Document Search using vector embeddings and keyword-based search.

## Domain
Healthcare

## Features
- Semantic Search
- Keyword Search
- Search Results Comparison
- Search Visualization
- Document Embeddings
- ChromaDB Vector Database

## Technologies Used
- Python
- Pandas
- NumPy
- ChromaDB
- Sentence Transformers
- Matplotlib

## Project Structure
- dataset/ - Documents, queries and search results
- notebook/ - Jupyter notebooks
- semantic_search.py - Semantic search
- keyword_search.py - Keyword search
- comparison.py - Search comparison
- visualization.py - Visualization

## How to Run
1. Install dependencies:
   pip install -r requirements.txt

2. Run semantic search:
   python semantic_search.py

3. Run keyword search:
   python keyword_search.py

4. Run comparison:
   python comparison.py

5. Run visualization:
   python visualization.py
